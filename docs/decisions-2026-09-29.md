# Решения первой пробы

## Движок
Выбрано: Godot 4.7.2, официальный Windows binary, GDScript, 3D.
Почему: быстрый запуск, небольшой дистрибутив и достаточно возможностей для проверки управления; UE5 остаётся кандидатом основной игры.
Цена отмены: перенос сцены и кода в другой движок; это прототип, не окончательная архитектура.
Где: project.godot, scripts/.

## Масштаб
Выбрано: одна конечная тестовая карта, восемь взрослых жителей, один управляемый отряд.
Почему: проверяем взаимодействие базы, вылазки и транспорта до масштабирования.
Цена отмены: расширение данных карты и симуляции; стартовое население не является лимитом проекта.
Где: scripts/game.gd.

## Визуальный стиль
Выбрано: собственные процедурные low-poly модели, тёплый вечерний свет, лес и заброшенная промышленная окраина.
Почему: сразу получаем цельную объёмную сцену без покупки ассетов.
Цена отмены: заменить модели, сохранив игровой код.
Где: scripts/world.gd, scripts/unit.gd.

Где: origin.
