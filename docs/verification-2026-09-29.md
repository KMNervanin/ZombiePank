# Проверка первой сцены

Дата: 29.09.2026. Windows, NVIDIA GeForce RTX 5080, Godot 4.7.2.stable.official.ed1daf0bf, OpenGL Compatibility.

## Результат

- Официальный Windows-дистрибутив проверен по SHA512-SUMS.txt из того же релиза.
- Импорт проекта завершён без ошибок.
- Gameplay smoke: 17 проверок, exit code 0.
- Ввод через viewport: 9 проверок, exit code 0, рендерер NVIDIA GeForce RTX 5080.
- Кадр после успешной вылазки, разгрузки и расширения базы сохранён в first-shelter.png и просмотрен.

Это автоматические сценарии внутри движка. Ручной пользовательский playtest ещё впереди; производительность на тысячах жителей не проверялась.

## Найдено и исправлено

- Человек оставался на месте, когда точка его строя попадала на палатку: поиск ближайшей свободной ячейки для мест в строю.
- Проверка сообщала ошибку, но завершалась с кодом 0: накопление числа ошибок и ненулевой итоговый код.
- Слишком яркий свет первого кадра: снижены прямой и фоновый свет, изменён ракурс, добавлены скатные крыши.
- Координаты синтетических кликов не учитывали масштаб окна: преобразование через screen transform viewport.
- Кнопки смещались при изменении высоты текста задания: постоянная минимальная высота блока задания.
- Кнопки могли забирать клавиатурный фокус: отключён focus у кнопок, клавиша паузы проверена после кликов.
- Суммарный груз при посадке мог превысить вместимость машины: посадка с избыточным грузом отклоняется с объяснением.

## Ограничения

Нет сохранений, детальной экономики, сценарного выхода за карту, смены времени суток, многотысячной симуляции и физики автомобиля. Карта и модели процедурные. Плановые дальнейшие изменения определяются после первой пользовательской пробы.
